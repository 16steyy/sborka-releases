# Настройки и частые проблемы

## Параметры проекта

Раздел «Параметры» в группе «Выпуск».

- Название, версия проекта, автор, описание.
- Загрузчик и его версия. «Найти последнюю» подставляет версию; пусто означает, что при экспорте будет взята последняя. Если сменить версию игры или загрузчик вручную, содержимое не переедет: для этого есть «Перенести на другую версию» ([check.md](check.md#перенос-на-другую-версию)).
- Заметки, видны только вам.
- **Окно игры**: название в заголовке и иконка на панели задач (их меняет мод FancyMenu; само главное меню настраивается в разделе «Главное меню»).
- Дублировать, удалить.

## Настройки приложения

Боковая панель → «Настройки» или `Ctrl+,`. Вверху страницы есть поле поиска по настройкам.

### Язык и внешний вид

| Настройка | Примечания |
| --- | --- |
| Язык интерфейса | Русский или английский; окно перезагрузится |
| Тема | Тёмная, графит, светлая |
| Акцентный цвет | Готовый или свой |
| Плотность списков | Обычная или компактная |
| Скругление углов | |
| Масштаб интерфейса, % | Меняет корневой размер шрифта |
| Иконки в списках | Показывать иконки модов или нет |
| Экономный режим | Убирает стекло, размытие и анимации. Помогает на слабых компьютерах и от батареи |
| Эффект стекла | Mica и Mica Tabbed (Windows 11), Acrylic и Blur (Windows 10 и 11; Acrylic может подтормаживать при перетаскивании окна) или выключен. В Linux эффект недоступен |
| Непрозрачность фона, % | Чем меньше, тем сильнее видно стекло |

### Интеграции

- **Ключ CurseForge API.** Нужен для поиска. Есть кнопка «Проверить».
- **Токен Modrinth.** Только для публикации. Нужно право создавать версии.
- **Токен загрузки CurseForge.** Для публикации файлов сборки. Это не тот ключ, что API-ключ.
- **Каталог по умолчанию.** Какой источник открывается первым.

Всё хранится только на этом компьютере, в `settings.json`, без шифрования.

### Новые проекты

Версия Minecraft, загрузчик, автор и версия проекта по умолчанию.

### Поведение

- Добавлять зависимости: обязательные ставятся вместе с модом.
- Разрешить beta и alpha: если релиза нет, берётся самая свежая версия.
- Моды CurseForge в `.mrpack`: формат не принимает ссылки на CurseForge, поэтому файлы кладутся внутрь архива.
- Моды не с CurseForge в архиве CurseForge: файлы Modrinth и внешние файлы кладутся в overrides экспорта.
- Фоновая проверка обновлений: выключена, каждый час, каждые 3 часа, каждые 6 часов, раз в сутки.
- Спрашивать перед удалением.
- Показывать снапшоты Minecraft в списках версий.
- Параллельные загрузки, от 1 до 16.
- Результатов на странице каталога.

### Тестовый запуск

- Я принимаю EULA Minecraft. Нужно для тестового сервера и клиента, на них держатся поиск виновника, слияние конфигов и проверки перед релизом. Текст: aka.ms/MinecraftEULA.
- Путь к `java.exe`. Пусто: Sborka выберет подходящую установленную Java сама.
- Память, ГБ, от 1 до 32.
- Ждать запуска не дольше: 2, 5, 10 или 15 минут. Если за это время сервер не дошёл до `Done`, а клиент до главного меню, это считается зависанием.
- Ник в тестовом клиенте: латиница, цифры и `_`, от 3 до 16 символов; пусто означает «Sborka». Вход офлайн, без аккаунта.

### Редактор

Размер шрифта (также `Ctrl`+колесо в редакторе), ширина отступа (2 или 4 пробела), автозакрытие скобок и кавычек, очистка пробелов в конце строк при сохранении.

### Данные

- Версия Sborka и кнопка «Проверить обновления».
- Мастер первого запуска.
- Открыть папку с данными.
- Очистить кеш ответов каталогов. Он ускоряет поиск, а без интернета служит запасным вариантом.
- Очистить кеш файлов модов. Это файлы, скачанные при установке, экспорте и глубокой проверке; при необходимости скачаются заново.
- Список Java, найденных на этом компьютере.

## Папки с данными

Папка: `%APPDATA%\dev.sborka.app` (Windows) или `~/.local/share/dev.sborka.app` (Linux).

```
settings.json, presets.json
packs/<id>.json        описание проекта
packs/<id>/            overrides/, client-overrides/, server-overrides/
history/<id>/          снапшоты и blobs/ (вне packs/, чтобы не попасть в экспорт)
bases/<id>/            конфиги по умолчанию: base/ и next/
registry/<id>.json     собранный реестр предметов
gallery/<id>/          выбранные скриншоты
test-server/<id>/      тестовый сервер, папка очищается перед запуском
test-client/<id>/      тестовый клиент, миры и настройки сохраняются
client/                файлы игры
cache/                 http/, files/, registry/
```

## Частые проблемы

**Поиск на CurseForge просит ключ.** Добавьте ключ API в «Настройки» → «Интеграции». Modrinth работает без ключа.

**Каталог не отвечает.** Если есть сохранённый ответ, показывается он. Нажмите «Повторить» или проверьте соединение.

**Тестовый запуск не стартует.** Примите EULA в настройках. Посмотрите карточку Java в окне запуска: если найденная Java слишком старая для этой версии Minecraft, поставьте новую или укажите путь в настройках.

**Уже идёт другой тестовый запуск.** Поиск виновника, слияние при обновлении и релиз используют один и тот же запуск. Дождитесь его конца или остановите. Если ещё открыт тестовый клиент, закройте игру.

**Окно тормозит.** Включите «Экономный режим» в «Настройки» → «Язык и внешний вид».

**Музыка не добавляется.** Для MP3, WAV и FLAC нужен `ffmpeg` в `PATH`. Либо переведите файл в `.ogg` (Vorbis) сами, либо установите ffmpeg.

**Редактор недоступен или скрипт «не поддерживается».** Плашка сообщает, какого мода не хватает. Добавьте его одним щелчком.

**«Файл изменился на диске» при сохранении квестов или конфига.** После открытия файл правил кто-то ещё, и Sborka не станет его перезаписывать. Откройте файл заново и повторите правку.

**Программа перестала запускаться после определённой даты.** Это бета-сборка со сроком. Поставьте новый релиз, проекты целы.
