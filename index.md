# Руководство пользователя Sborka

Sborka — настольный редактор сборок Minecraft. Вы ищете моды на Modrinth и CurseForge, собираете проект из модов, ресурспаков и шейдеров, правите конфиги, скрипты KubeJS и квесты FTB, проверяете результат на ошибки, запускаете сборку на отдельном сервере или клиенте и экспортируете её для лаунчеров или публикуете.

Руководство построено так же, как сама программа.

| --- | --- |

## Установка

Установщик берут на странице релизов на GitHub:

- Windows: `.exe` или `.msi`
- Linux: `.deb`, `.rpm` или `.AppImage`

Сейчас Sborka в закрытой бете. В строке состояния виден счётчик вида «Бета до 15.12.2026, осталось N дн.»; за 7 дней до конца он становится жёлтым. После этой даты сборка не запускается, нужно поставить новую. Проекты при этом не удаляются.

**Первый запуск.** Если проектов ещё нет, открывается мастер: тема и автор, поиск Java и согласие с EULA, ключ CurseForge, затем выбор, с чего начать. Любой шаг можно пропустить, мастер открывается снова из «Настроек» → «Данные» или из палитры команд.

**Обновления.** При запуске (не чаще двух раз в сутки) Sborka проверяет новую версию. Если она есть, в строке состояния появляется «Доступна версия …»: там список изменений и кнопка «Обновить и перезапустить». Проекты и настройки сохраняются. Проверку можно выключить в «Настройках» → «Поведение», проверить вручную — в «Настройках» → «Данные».

### Что понадобится дополнительно

- **Ключ CurseForge API.** Без него работает только Modrinth. Получить его можно на console.curseforge.com, вставить в настройках.
- **Java.** Нужна для тестового сервера и клиента. Sborka ищет установленную Java сама, путь к `java.exe` можно указать вручную.
- **ffmpeg** в `PATH`. Нужен только для музыки в MP3, WAV и FLAC. Файлы `.ogg` добавляются и без него.
- **EULA Minecraft.** Тестовые сервер и клиент запускаются, только когда вы приняли EULA в настройках, раздел «Тестовый запуск».

### Сборка из исходников

Нужны Node.js 18+, Rust и [зависимости Tauri](https://tauri.app/start/prerequisites/). На Ubuntu и Debian:

```sh
sudo apt install libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf build-essential
```

```sh
npm install
npm run tauri dev      # приложение целиком
npm run tauri build    # установщики в src-tauri/target/release/bundle
npm test               # тесты бэкенда
npm run test:js        # тесты логики редакторов
npm run check:i18n     # у каждой строки есть английский перевод
npm run verify         # всё, что проверяет CI
```

## Окно программы

- **Заголовок окна.** Кнопка боковой панели, поле поиска, которое открывает палитру команд, и кнопки окна. Если в редакторе есть несохранённые правки, при закрытии любым способом (в том числе Alt+F4) программа спросит.
- **Боковая панель.** У разделов проекта бывают метки: число доступных обновлений у «Модов и паков», число ошибок или предупреждений анализатора у «Диагностики» (проверка идёт в фоне после каждого изменения списка модов), несохранённые файлы у «Конфигов и файлов». Без открытого проекта в ней список проектов, а ниже «Каталог», «Пресеты» и «Настройки». С открытым проектом в ней разделы этого проекта. Меню наверху переключает проекты, «Все проекты» закрывает текущий. Каталог и настройки открываются, не выходя из проекта.
- **Строка состояния.** Доступность каталогов (Modrinth работает без ключа, для CurseForge видно, указан ли ключ), текущая фоновая задача, версия игры и загрузчик, число включённых файлов, счётчик беты.
- **Всплывающие сообщения.** Появляются в углу, закрываются щелчком.
- **Перетаскивание файлов.** Файл `.mrpack` или `.zip`, брошенный в окно, импортируется как проект. Если проект открыт, остальные файлы копируются в его overrides, в папку, выбранную в разделе «Конфиги и файлы».

### Разделы проекта

Боковая панель делит их по этапам работы:

| Группа | Раздел | Для чего |
| --- | --- | --- |
| Сборка | Моды и паки | Список модов, обновления, группы |
| | Конфиги и файлы | Редактор всего, что попадёт в сборку |
| | Геймплей | Лут, торговля, руды, мобы, книги, достижения, свои предметы |
| | Ресурспак | Текстуры и музыка |
| | Главное меню | Меню игры и название окна (через FancyMenu) |
| | Квесты | Книга FTB Quests (только если она есть в проекте) |
| | Перевод | Перевод модов и квестов |
| Проверка | Обзор | Размер, требования, конфиги по умолчанию |
| | Диагностика | Конфликты, рецепты, клавиши, краш-логи, поиск виновника |
| | История | Снапшоты, сравнение, откат |
| Выпуск | Экспорт и релиз | Релиз, экспорт, тестовый запуск, публикация |
| | Параметры | Название, версии, загрузчик, перенос |

### Палитра команд

Нажмите `Ctrl+K`, наберите несколько слов и нажмите Enter. Находит проекты, разделы и большинство действий: экспорт, публикацию, запуск тестового сервера, проверку обновлений, копирование кода сборки, смену темы. Порядок слов не важен.

В открытом проекте палитра ищет и по его содержимому: моды (открывает таблицу с фильтром), файлы (открывает в редакторе), предметы и рецепты из реестра и строку «Искать … внутри всех файлов».

### Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl+K` | Палитра команд |
| `Ctrl+B` | Показать или скрыть боковую панель |
| `Ctrl+,` | Настройки |
| `/` | Поиск в каталоге |
| `1` … `9` | Разделы проекта в порядке боковой панели |
| `Ctrl+Z`, `Ctrl+Y` | Отменить и повторить правку списка модов |
| `Ctrl+S` | Сохранить файл в редакторе |
| `Ctrl+F` | Найти в файле |
| `Ctrl+Space` | Подсказки в редакторе |
| `Shift`+щелчок | Выбрать диапазон модов |
| `?` | Показать этот список в программе |

Клавиши с буквами и цифрами не срабатывают, пока вы печатаете в поле или открыт диалог.

## Языки

Интерфейс и сообщения программы на русском и английском. Язык меняется в «Настройках», раздел «Язык и внешний вид». После смены окно перезагружается; если в редакторе есть несохранённое, программа спросит об этом заранее.

## Где всё лежит

Всё хранится в папке данных приложения: `%APPDATA%\dev.sborka.app` в Windows, `~/.local/share/dev.sborka.app` в Linux. Состав папки описан в [settings.md](settings.md#папки-с-данными). Ключи и токены лежат там же в `settings.json` без шифрования.
